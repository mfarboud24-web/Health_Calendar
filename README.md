# تقویم سلامت
با این تقویم مناسبتهای سلامت در طی سال به شما نمایش داده می شود.می توانید برای برنامه ریزی در طی سال آمادگی لازم را کسب کنید.این تقویم بیشتر مناسب پرسنل بهداشت و درمان است ولی همه افراد می توانند از آن استفاده کنند.زبان برنامه html است و برای کامپیوتر و موبایل به راحتی بدون هیچگونه نصب و تنظیماتی قابل اجرا است.
